# Kidney Disease Prediction

## Project Description
This project predicts kidney disease using machine learning classification algorithms.

## Models Used
- Logistic Regression
- KNN Classification
- Random Forest
- Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Conclusion
The four classification models were compared using different evaluation metrics.
The Logistic Regression model and Random Forest model with the highest accuracy was identified.
